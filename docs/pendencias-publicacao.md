# Pendências de publicação

- [ ] O responsável criou ou autorizou um repositório próprio (`owner/jornada-diaconal`).
- [ ] Os arquivos deste pacote foram enviados ao GitHub, sem documentos pessoais.
- [ ] GitHub Pages habilitado para Actions.
- [ ] Foi criado um projeto Railway para **este** sistema, não misturado à pesquisa anterior.
- [ ] PostgreSQL inicializado com `api/sql/001_init.sql`.
- [ ] API PHP implantada com `DATABASE_URL` privado.
- [ ] `ALLOWED_ORIGINS` aponta para a origem real do GitHub Pages.
- [ ] Domínio HTTPS da API definido em `frontend/public/config.js`.
- [ ] Administrador criado pelo console, sem armazenar senha no GitHub.
- [ ] Testes de login, permissões e grupo de cuidado concluídos com dados fictícios.
- [ ] Backup, privacidade e autorização para importar dados reais definidos.

**Importante:** o repositório e o deploy **não** devem ser declarados como prontos até que existam URLs verificadas e os testes de operação tenham sido executados.
